## 1. Agent Communication Chain Recreation — Roster, Duties, Findings, Endings

The SRL-2015 pipeline runs an identical 13-agent roster on every one of the 8 reports (4 hosts x disk/memory): memory, timeline, filesystem, artifact, discovery, null_session_baseline, mail, yara_hunt, injection_detector, the three deterministic signature agents (t1546_008_accessibility_ifeo_hijack, t1059_001_iex_loopback_c2, t1071_001_svchost_outbound_http), and the hunt correlator. The plan never varies; what varies per host/modality is which agents go stable vs land in gaps[]. Disk runs are dominated by artifact (103-188 findings), timeline (1-219), filesystem (15-31) and hunt; memory runs are dominated by agent.memory (rollup '500 finding(s)' on controller/nfury, yielding 432/399 findings.agent=memory) plus injection_detector and hunt. agent.discovery and agent.mail are commissioned-but-silent on ALL 8 reports (15 zero-finding rollups each, permanently in gaps[]; mail errors with 'Header' object has no attribute 'strip' on memory runs). agent.yara_hunt is additionally a gap on controller disk only. memory.skip on disk runs (and on the nromanoff/xp 'memory' runs whose images were not RAM dumps) is a legitimate decline, not a failure. Every report shows the same two-signature iteration pattern: iter0 dropped=[], iters1-14 list the full producing roster in dropped_agents while stable_agents and gaps stay constant; critic_score pinned 1.0, should_halt=false, termination via status=budget_exhausted.

**Cross-host corroboration:** The 13-agent plan is byte-identical across all 4 hosts and both modalities ($.iterations[0].plan in all 8 reports), so roster differences are purely outcome-driven. Disk vs memory split: disk runs activate the disk producers (timeline/filesystem/artifact via mcp.get_timeline, mcp.fls, mcp.extract_files*, mcp.get_registry, mcp.list_files) while agent.memory and injection_detector decline (memory.skip / memory.injection.skipped); memory runs invert this — agent.memory + injection_detector + t1071_001 produce (driven by a single mcp.get_pslist on controller/nfury) while artifact/timeline (and filesystem on controller/nfury) become 15x-retried gaps. Host-level corroboration: discovery and mail are silent on all 8 reports (universal pipeline gap, not host-specific); yara_hunt gaps ONLY on controller disk while matching CAPE_Cobaltstrikestager on nromanoff disk; null_session_baseline spikes to 22 findings only on nromanoff disk (T1087.002 discovery host); timeline yields 219/193 findings on nfury/xp disks but only 1 on controller/nromanoff disks (log2timeline degradation visible in disk.run.log); nromanoff and xp memory runs are near-identical 10-finding skeletons because both staged memory images were rejected by MemoryAgent as non-RAM, whereas controller/nfury memory runs are true Volatility triages (432/399 memory findings incl. T1003.002 hashdump on the DC). All 8 reports share the same ending mechanics: critic_score=1.0 every iteration, should_halt=false, status=budget_exhausted at 15/15.

# Challenge "Notch It Up" — generated report artifacts

These four files are the multi-tier report artifacts for case `CHALLENGE-NOTCHITUP` — an
end-to-end Agentropix-SIFT memory triage of a 1.6 GB raw Windows x64 VirtualBox RAM image
(`/cases/Challenge_NotchItUp/Challenge.raw`, CTF challenge). They are generated by the
Agentropix report engine (ADR-024) from the case's sealed, examiner-approved findings: the
engine fuses the sealed `report_generate(profile="full")` snapshot and the captured MCP step
outputs into one comprehensive document — executive dashboard (KPIs, risk matrix), forensic
sections (5-entry IOC catalogue, process/network artefacts, MITRE T1055/T1047 mapping, detailed
findings, timeline) and a coverage attestation — plus a 1-page executive summary, each rendered
to `.md` (canonical) and `.pdf` (share-out render).

The approval step in this demo run was simulated: in the report's own words, *"the showcase
approval was Playwright-automated, standing in for the human HMAC sign-off, which is a deliberate
Hard-Stop in real cases."* All five findings carry per-finding HMAC-SHA256 seals.

## Honest notes

The reports flag these themselves; none are hidden:

- **Simulated approval.** The DRAFT → APPROVED transitions were Playwright-automated for the
  showcase, standing in for the human HMAC sign-off (a deliberate Hard-Stop in real cases).
- **Evidence-internal IPs.** The `10.0.2.15` guest address and the Google-range socket endpoints
  are content recovered from inside the RAM image, labelled **evidence-internal** — not live
  infrastructure. All 97 sockets are benign browser traffic; no in-memory C2 channel is observable.
- **Zeroed RWX caveat.** The 4 KB zeroed RWX VADs in explorer.exe and chrome.exe (F-NOTCH-002/003)
  are held at medium confidence — a zeroed RWX page can be benign allocator/JIT behaviour, so they
  corroborate rather than confirm.
- **Timings not recorded.** Per-tool wall-clock durations were not captured in the step JSONs; the
  performance section reports recovered-row counts ("not recorded") instead of inventing timings.
- **svcscan not run** in this triage path — the services table is honestly empty.
- **RAM-only limits.** Initial access "Not observed" and dwell "Not derivable" from a single
  snapshot; the report recommends acquiring on-disk and longitudinal artefacts to close that gap.

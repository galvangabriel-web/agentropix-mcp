# AMF Windows sample001 — generated report artifacts

These four files are the multi-tier report artifacts for case `AMF-WIN-SAMPLE001` — a Volatility 3
memory triage of a 511 MiB raw Windows XP RAM image (`sample001.bin`, from *The Art of Memory
Forensics* sample set). They are generated by the Agentropix report engine (ADR-024) from the
case's sealed, examiner-approved findings: the engine fuses the sealed `report_generate(profile="full")`
snapshot and the raw MCP captures into one comprehensive document — executive dashboard (KPIs,
risk matrix), forensic sections (IOC catalogue, process/network artefacts, MITRE ATT&CK mapping,
detailed findings, timeline) and a coverage attestation — plus a 1-page executive summary, each
rendered to `.md` (canonical) and `.pdf` (share-out render).

One caveat the reports themselves state up front: the single DRAFT → APPROVED transition in this
demo run was Playwright automation with the recorded reason **"SIMULATED examiner approval (demo
only)"** — in the reports' own words, *"NOT a human HMAC sign-off … In a real case this transition
is a Hard-Stop requiring a human examiner's HMAC challenge-response."*

## Honest notes

The reports flag these themselves; none are hidden:

- **Simulated approval.** The one approval was Playwright demo automation (approval ID `4a881577…`),
  explicitly labelled "SIMULATED examiner approval (demo only)" throughout; the report recommends
  a genuine human examiner HMAC sign-off before the case is treated as evidentiary.
- **Empty netscan.** `get_netscan` returned **0 sockets** — recorded as an honest empty result on
  this XP-era image, not padded with invented network artefacts.
- **Zero IOCs promoted.** RWX VADs are host-internal memory artefacts; with no sockets and no
  external hashes, the IOC catalogue is honestly empty (the evidence SHA-256 is custody, not threat).
- **malfind timeout re-run.** The `get_malfind` pass exceeded the default 180 s SDK request bound
  and was re-run standalone with a 300 s `callTool` timeout, completing in 75 s.
- **Raw image quirk.** `ewfinfo` returned empty metadata (no EWF header on a raw `.bin`) — the
  authoritative size came from `evidence_register`, per the appendix.
- **RAM-only limits.** Initial access "Not determined" and dwell "Indeterminate" — a single RAM
  snapshot cannot establish them, and the report says so instead of guessing.

# CTF-CONTACT-ME-MEM — generated report artifacts

These four files are the multi-tier report artifacts for the `contact_me` memory-triage run
(1 GiB raw RAM capture, case `CTF-CONTACT-ME-MEM`). They were generated by the Agentropix-SIFT
report engine (ADR-024) from the case's sealed findings: `report_generate(profile=full)` fuses
the sealed case data (executive summary, findings, IOCs, timeline) plus the run's captured tool
outputs into one comprehensive document — executive dashboard (KPIs, risk matrix), forensic
sections (hosts, network, detailed findings, timeline), and a coverage attestation — and a
parallel 1-page executive summary. Each tier is rendered to `.md` (canonical) and `.pdf` (share).

The single approved finding behind these reports was approved in a **simulated** examiner
sign-off, demo only — the comprehensive report says so itself: "a SIMULATED examiner approval
(Playwright-driven HMAC challenge-response on the Examiner Portal — no human clicked Approve)",
and again: "The examiner sign-off in this demo was SIMULATED (automated HMAC), not a human
approval." A production case requires an interactive human examiner sign-off.

## Honest notes

This case is an unprofileable, honest-negative capture. Volatility3 2.28.0 could not validate
a Windows kernel symbol table for the image, so every kernel-dependent plugin returned
placeholder rows (pslist: 11 rows, all `pid:0` / `name:"unknown"`), empty counts (netscan
`socket_count 0`, malfind `hit_count 0`, svcscan `service_count 0`), or a requirements error
(cmdline). The reports therefore document **why no compromise verdict is possible** — the
controlling fact is a tooling/profile mismatch, not the host's security state — and the
recommendation is to re-acquire or supply a matching symbol table, never to read the empty
output as "clean".

That is the point of these artifacts: a sealed, HMAC-attested report of a *negative* result.
The pipeline recorded what it could not resolve, gated the finding through the evidence gate,
and sealed the inconclusive outcome instead of inventing processes or IOCs — anti-hallucination
discipline applied end-to-end. Run transcript: [`../EXECUTED-RUN.md`](../EXECUTED-RUN.md).
